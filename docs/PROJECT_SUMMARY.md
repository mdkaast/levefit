# Levefit: сводка по текущей версии (26.10.2026)

Levefit — Telegram Mini App для силовых тренировок с ИИ-тренером. Репозиторий: github.com/mdkaast/levefit, ветка `main`. Рабочая версия: https://217-177-72-87.sslip.io (открывается из бота).

## Главный принцип
Числа и решения (вес, повторы, разгрузка, реакция на боль) считает детерминированный движок правил. Языковая модель только объясняет решение человеческим языком, её ответ проверяется: веса берутся только из решений движка, при боли совет врача, без ссылок. Каждое решение пишется в журнал (версия правил, решения, кто объяснил, правки пользователя).

## Что уже работает

**Фаза 0. Основа интерфейса.** Дизайн-токены, шрифты, набор компонентов, навигация из пяти вкладок, флаги функций, заготовка под 3D, исправления найденных ошибок.

**Фаза 1. Ядро тренировки.**
- Движок: двойная прогрессия, поправка по запасу повторений (RIR), сброс после второй неудачи, разгрузка (по сигналам и плановая), боль, низкая готовность, возвращение после перерыва, лёгкий день, прогрессия для упражнений с собственным весом.
- Цикл тренировки: «Сегодня», готовность, активная тренировка с таймером отдыха, оценка упражнения, итог с принять/изменить, пропуски.
- Офлайн-очередь: подходы не теряются без сети и не дублируются (идемпотентные запросы).

**Фаза 2. Каталог и программы.**
- 374 упражнения: паттерн движения, мышцы с весами, инвентарь, уровень, шаг прибавки, флаги осторожности, замены.
- 22 шаблона программ (T01–T22), матрица подбора из 454 строк (цель × дни × уровень × инвентарь плюс условия: перерыв, 50+, сессия до 30 минут, сплит). Пустых слотов нет.
- Экраны: «Тренировки» → Неделя / Программы / Упражнения; карточка упражнения с заменами и вашей историей; карточка программы с объёмом по группам мышц.
- Шесть целей в онбординге: сила, сила и масса, масса, вернуться в форму, похудение, общая форма.

Сопутствующее: админ-панель (метрики, журнал ИИ), напоминания через бота, анатомическая схема мышц, задачи и достижения.

## Технологии
- API: FastAPI, SQLAlchemy 2, Alembic (миграции 0001–0015), Postgres 16 в проде, SQLite локально и в тестах.
- Веб: React 18, TypeScript, Vite, Telegram SDK, vitest.
- Бот: aiogram. Инфраструктура: Docker Compose, Caddy, GitHub Actions. Один VPS (1 vCPU, ~1 ГБ ОЗУ).
- Проверки на момент выкладки: API 241 тест, веб 41 тест, линтеры и сборка чистые.

## Где что лежит
- `apps/api` (код, движок `app/engine`, каталог `app/content`, миграции), `apps/web`, `apps/bot`.
- `docs/`: `engine.md` (правила движка), `catalog.md` (каталог и шаблоны), `decisions.md` (принятые решения), `BACKLOG.md` (статус задач по ID), `AUDIT.md`, `server.md` (сервер и выкладка).
- `data/` и `mockups/`: исходные данные каталога и макеты. `scripts/build_catalog.py` пересобирает каталог, `scripts/deploy_vps.sh` выкладывает на сервер.

## Ограничения (честно)
- Шаблоны не проверены тренером и врачом ЛФК (все помечены `verified = false`). У 40 упражнений неустоявшиеся русские названия.
- Мышцы и их вклад в объём разобраны скриптом из текста каталога, веса не проверены.
- Движок умеет только двойную прогрессию. Шаблоны с линейной, стадийной, волновой, блочной, лестничной и временной моделями временно ведутся запасными шаблонами (T02→T09, T03/T04/T05/T21/T22→T07, T06→T09, T16→T09, T17→T19); экран программы об этом сообщает.
- Подсказок по технике и видео нет, лицензии на медиа не решены.
- Юридический блок (согласие, 18+) отложен: в коде метки `LEGAL-LATER`.
- В онбординге «дом» означает гантели; варианты «дом со штангой» и «гиря» есть в API, но не в интерфейсе.
- На реальных телефонах проверено выборочно. Мобильный Telegram кэширует страницу: для сброса менялся номер версии в адресе приложения (`?v=2`).

## Выкладка и правила команды
- Выкладка: `scripts/deploy_vps.sh` из текущего коммита; перед миграциями обязателен `pg_dump` (копия делается на сервере в `/opt/levefit/backups`).
- В `main` вливаем после проверки владельцем; секреты лежат только на сервере.
