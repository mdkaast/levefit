# Каталог упражнений и шаблоны программ

Фаза 2. Данные пакета (`data/exercises.json`, `data/programs_T01-T22.md`) преобразованы в структурированные таблицы. Исходные файлы остаются эталоном и лежат в репозитории.

## Что в базе

| Что | Сколько | Где |
| --- | --- | --- |
| Упражнения каталога | 374 (336 силовых, 12 кондиции, 26 мобильности и разминки) | таблица `exercises`, файл `apps/api/app/content/exercises.json` |
| Мышцы и группы интерфейса | 31 мышца, 18 групп | `muscles`, `exercise_muscles`, `app/content/muscles.py` |
| Шаблоны программ T01–T22 | 22 | `program_templates` (дни и слоты в поле `spec`), `app/content/templates_data.py` |
| Лестницы прогрессий | 18 | `LADDERS` в `templates_data.py` |
| Матрица выбора | 454 строки (450 основных и 4 условных) | `template_matrix`, `app/content/matrix.py` |

Прежние 24 упражнения не потеряны: 22 из них сопоставлены с каталогом по названию и сохранили свои `id` (история подходов цела), «Бег» и «Мобильность плеч» остались как есть. Пользовательские упражнения не затрагиваются.

## Как это собирается

1. `python -X utf8 scripts/build_catalog.py` читает `data/exercises.json`, разбирает сокращения (инвентарь, уровень, шаг, e1RM, мышцы, флаги, замены) и пишет `apps/api/app/content/exercises.json` и `import_report.json` (что не удалось сопоставить). Результат закоммичен: образу API нужны только файлы внутри `apps/api`.
2. `python -m app.content.seed` загружает всё в БД. Запуск идемпотентен, образ API выполняет его при старте после миграций. Ничего не удаляет.
3. Миграция `0015` только добавляет столбцы и таблицы; откат (`downgrade`) удаляет их.

## Подбор упражнения в слот

`app/content/resolver.py`: кандидаты слота в заданном порядке → тот же паттерн движения → соседний паттерн (например, нет турника → горизонтальная тяга). Учитываются инвентарь (есть хотя бы одна альтернатива целиком), уровень (кроме явных кандидатов шаблона) и флаги нагрузки по жалобам (колено, поясница, плечо, локоть и запястье, шея, таз).

Инвентарь: `gym`, `home_barbell`, `dumbbells`, `bodyweight`, `kettlebell`. Из онбординга сейчас: зал → `gym`, дом → `dumbbells`, без оборудования → `bodyweight` (выбор дома по подробным признакам появится вместе с экраном «Оборудование» в профиле).

## Матрица и условия

Любой ответ онбординга (цель × дни × уровень × инвентарь) даёт шаблон. Условия применяются после основной таблицы в порядке: «сессия до 30 минут» (заменяет), «сплит по просьбе», «50+», «перерыв ≥ 14 дней» (ставится первым: T14 → T20 → основной). Проверено тестом: на всех 450 основных строках у всех назначенных шаблонов нет пустых слотов.

Цели теперь шесть: сила, сила и масса, масса, вернуться в форму, похудение, общая форма. Прежняя цель «форма» принимается и читается как «общая форма».

## Что приложение не обещает

- **Прогрессия шаблонов.** Движок ведёт двойную прогрессию. Шаблоны с другими моделями (линейная за сессию T02, стадии T03, волны T04–T06, блоки T21–T22, лестницы T16, время T17) помечены `engine_ready = false`; для них указан запасной шаблон с двойной прогрессией (`fallback`), и API сообщает об этом (`usable_note`). Это продуктовое решение на время, пока модели не реализованы.
- **Вычитка.** Все шаблоны `verified = false`: ревью тренером и врачом ЛФК (D8) не проводилось. Из каталога `verified = false` у 40 упражнений: это ровно список «неустоявшихся названий» из `data/progression_ladders_and_ru_names.md` (3.13).
- **Мышцы** разобраны из текста каталога скриптом. Основные и вспомогательные мышцы взяты как в данных (часть до «;» — основные), вклад в объём 1,0 и 0,5; веса `volume_weight` не проверены. У 38 упражнений мышц нет в источнике (разминка, мобильность, кондиция), у 15 силовых они выведены по паттерну (`muscles_source = pattern_default`).
- **Шаг прибавки.** Берётся из колонки «шаг» каталога (штанга 2,5 кг, гантели 2,5 кг, стек тренажёра 5 кг, гиря 4 кг). Подключение шага к движку упражнения за упражнением — следующий шаг фазы 3.
- **Техника и медиа.** Подсказок и видео в каталоге нет: поля `cues` и `media` заложены, интерфейс показывает «появится позже».
- **Ссылки на старые коды.** Девять ссылок в замене вида `hp04`, `vp14` указывали на прежнюю нумерацию записей и отброшены (см. `import_report.json`).
- **Дубли.** У 53 упражнений в данных есть синонимы (`aliases`); отдельных записей-дублей нет.

## API

`GET /catalog/groups`, `GET /catalog/exercises` (поиск, группа, паттерн, уровень, «подходит вам», страницы), `GET /catalog/exercises/{id}` (карточка с мышцами, флагами, заменами), `GET /catalog/exercises/{id}/substitutes` (сценарий, инвентарь, жалобы), `GET /programs`, `GET /programs/recommend`, `GET /programs/{id}` (слоты с упражнениями под инвентарь, объём по группам мышц).
