## B. Корректировки (`tz-corrections.md`): в коде пока нет ничего

| Раздел | Что нужно сделать | Статус |
| --- | --- | --- |
| 1. Терминология | Квест → «задание» везде: таблицы `quests`→`tasks`, `user_quests`→`user_tasks`, `GET /quests`→`GET /tasks`, `xp_events.source = quest_*`→`task_*`, вкладка и тексты, коды `daily_*`/`weekly_*`. Нужна миграция с переименованием и заменой значений источников в журнале XP | ❌ |
| 2. Ранги | Поле `characters.rank`, чистая функция от уровня + тесты, границы в конфиге; отображение в профиле | ❌ |
| 3. Задания | Типы `main` / `minor` / `recovery` в `tasks.kind`; выдача каждое утро; в день отдыха — задание восстановления; пропуск заменяет основное задание на восстановление без списания XP | ❌ |
| 3. Расписание | Нужны «тренировочные дни» недели. Сейчас есть только число тренировок в неделю | ❌ |
| 3. Размер задания | ИИ подбирает объём основного задания по уровню, истории и самочувствию | ❌ |
| 3. Режим паузы | `users.mode` (`active`/`paused`) и `paused_at`; в паузе нет заданий с нагрузкой, серия не сгорает; переключатель в профиле | ❌ |
| 4. Очки уровня | `characters.level_points`: +1 за каждый новый уровень, показ в профиле | ❌ |
| 5. Тексты | Нейтральный деловой тон в приложении и боте по образцам; лимит напоминаний в сутки в конфиге; всё в файлах локализации | 🟡 (тексты есть, тон и лимит нет) |
| 5. Оформление | Сдержанные карточки, без кричащих эффектов и анимации наград | ❌ — **противоречит текущему неоновому дизайну**, см. вопрос ниже |

| 6. Шаг роста нагрузки | Допустимый шаг (сейчас 10% / 2,5 кг) вынесен в конфиг; согласовать с тренером | 🟡 |
| 7. Этап 3 | Достижения (титулы) | ❌ |
| 7. Профиль | «Профиль персонажа» вместо экрана статуса: ранг, очки уровня, характеристики, достижения | ❌ |

## C. Что нужно решить до работы

1. **Стиль интерфейса.** Корректировки просят сдержанное оформление без кричащих эффектов; текущий дизайн (чёрный фон, неон, анимированная подсветка) сделан по вашим референсам. Нужно решение.
2. **Тренировочные дни.** Для «тренировка по плану в тренировочный день» и дней отдыха нужно расписание.
3. **Награда за вес.** XP за запись веса (5) противоречит разделу 6. Убрать или оставить?
4. **Кто выдаёт ежедневное задание.** ИИ каждое утро (расход токенов, нужен ключ) или правила на сервере, а ИИ только после тренировки.

## D. Предлагаемый порядок

1. Терминология и переименования (миграция, API, интерфейс, тесты).
2. Ранги и очки уровня, профиль персонажа.
3. Расписание и задания трёх видов, режим паузы, пропуск без штрафа.
4. Тексты по образцам для приложения и бота, лимит напоминаний.
5. Достижения.
6. План следующей тренировки из решения ИИ.
7. Безопасность: общий лимит запросов, бэкапы и шифрование, живая проверка ИИ.
