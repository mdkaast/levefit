# Спецификация макетов Levefit (33 экрана)

Этот документ описывает каждый макет из `mockups/` и связывает его с задачами бэклога (`docs/BACKLOG.md`). Макеты — интерактивные HTML-страницы формата `.dc.html` (открываются в браузере или в редакторе, который понимает этот формат), размер экрана **390 × 844**. Расположение на холсте и порядок потоков — в `mockups/canvas.json` (поле `boards`).

**Как читать «Состояния»**: это то, что в макете уже переключается руками (стейт в скрипте экрана). Всё остальное (загрузка, ошибка, пусто, офлайн) нужно сделать по общим правилам, раздел 11.

**Важное про названия.** В макетах тренер называется «тренер». В продукте он называется **ИИ-тренер** (решение владельца: ключевая фишка, не убирать). Заголовки и подписи, где идёт речь о тренере, можно писать «ИИ-тренер», а в пояснениях оставлять «тренер». Числа и решения считает движок на правилах, ИИ-тренер их объясняет и ведёт диалог.

**Демо-данные** в макетах (82 кг, Верх A, жим 80 кг, 1 487 / 2 450 ккал, уровень 7 и т. д.) — примеры, не хардкод.

## 1. Карта потоков

```
ПЕРВЫЙ ЗАПУСК
On1 Ценность → On2 Согласие* → On3 Цель и опыт → OnSport Направления → OnSex Пол и силуэт
  → On4 Рабочие веса → On5 План готов → Today
  (*по решению владельца: за фичефлагом, выключен; шаги текущего приложения «имя / рост / вес /
    возраст / образ жизни / режим тренировок» встраиваются между On3 и On4)

ТРЕНИРОВОЧНЫЙ ЦИКЛ
Today → Ready (готовность) → Workout → Rest (между подходами) → Rate (оценка упражнения)
  → … повтор по упражнениям … → Summary (итог и решение) → Today
Missed — сообщение бота о пропуске → Week

ТРЕНИРОВКИ (вкладка)
Week ⇄ Programs ⇄ ExLib (сегментный переключатель «Неделя / Программы / Упражнения»)
Programs → ProgramDetail → On5 («Выбрать программу»)
ExLib → Exercise → Workout (замена)

ПРОФИЛЬ / АТЛЕТ
Athlete → Directions → OnFocusF | OnFocusM (зал) | FocusQual (бег, силовые виды, йога, функциональный, дом)
Athlete → Challenges
Athlete/Today → Pro

ПИТАНИЕ (вкладка)
Nutrition ⇄ Recipes (переключатель «Дневник / Рецепты»)
Nutrition → FoodAdd | NutritionGoal;  Recipes → RecipeDetail → Nutrition («Добавить в ужин»)
```

Нижняя навигация (5 вкладок): **Сегодня** (Today), **Тренировки** (Week), **Питание** (Nutrition), **Прогресс** (Progress), **Атлет** (Athlete).

## 3. Первый запуск

### 1.1 `On1-Value` — Ценность
- Заголовок «Тренер, который объясняет следующий шаг». Пример решения: карточка «↑ Повысить · Жим лёжа 77,5 → 80 кг» с тремя подходами 8/8/8 и пояснением.
- Три тезиса (решения по правилам; растёт от выполненного плана; пропуск не обнуляет прогресс), «5 вопросов · около 2 минут», кнопка «Начать».
- Motion: «скелет» в фоне медленно дрейфует; карточка примера входит с пружиной, числа 77,5 → 80 «докручиваются», стрелка ↑ рисуется.
- Бэклог: B1 (текст про ИИ-тренера оставить, A3 отменена решением владельца).

### 1.2 `On2-Consent` — Согласие на данные (шаг 1 из 6)
- Экран «Какие данные мы храним». В макете есть; **реализовать за фичефлагом, по умолчанию выключен** (юридический блок отложен, `LEGAL-LATER: A1`).
- Бэклог: A1–A2 (фичефлаг).

### 1.3 `On3-Goal` — Цель и опыт (шаг 2 из 6)
- Цели приводятся к матрице каталога: Сила, Сила и масса, Масса, Вернуться в форму, Похудение, Общая форма. Опыт (с вопросом о перерыве), число дней. Ссылка вперёд → OnSport.
- Бэклог: B6, B7.

### 1.4 `OnSport` — Направления (шаг 3 из 6)
- «Чем занимаетесь?». Мульти-выбор карточек: зал, пауэрлифтинг, кроссфит, функциональный, бег, йога, дом (общеукрепляющие), универсальный. Счётчик «N направления».
- Состояние по умолчанию: выбраны зал и бег. Граничный случай «0 направлений» — кнопка недоступна с подсказкой.
- «Универсальный» взаимоисключающ с остальными или включает все (решение: исключающий, автоматическое распределение).
- Motion: выбор карточки — scale 1→1.02 + свечение рамки + haptic light; счётчик roll.
- Бэклог: B8, E1.

### 1.5 `OnSex` — Пол и силуэт (шаг 4 из 6)
- «Выберите силуэт». Мужской / женский (+ «Не указывать» → пользователь выбирает силуэт сам). Силуэт определяет модель для всех 3D-экранов.
- **3D-силуэт** живой (см. раздел 6 промпта): медленное вращение, смена модели cross-fade/morph 400 мс. В макете PNG: показана передняя половина, внутренний overflow-бокс.
- Бэклог: B9, E5.

### 1.6 `On4-Weights` — Рабочие веса (шаг 5 из 6)
- «Текущие рабочие веса» по базовым упражнениям; шаговые поля; в плане стартовые значения подбираются по уровню.
- Бэклог: B12.

### 1.7 `On5-Plan` — План готов (шаг 6 из 6)
- «Верх / низ · 3 дня», «Сила и масса · полный зал · ~55 минут». Три дня: Пн Верх A (Сегодня), Ср Низ, Пт Верх B с кратким составом и «+N» упражнений. Блок «Подобрано под вас: показаны не все упражнения» со ссылкой «Акцент» → OnFocusM. Блок «Как тренер будет решать» (двойная прогрессия). «Напоминания от бота: Пн · Ср · Пт в 18:30 и сигнал конца отдыха». Кнопки «Начать первую тренировку» → Ready/Today, «Позже».
- Состав дней берётся из матрицы выбора шаблонов (`data/programs_T01-T22.md`, раздел 5.6).
- Бэклог: B12, D3, D4.

## 4. Тренировочный цикл

### 2.1 `Today` — Сегодня
- Шапка «Сегодня», дата, «Ур. 7». Карточка «Тренировка сегодня»: Верх A, «5 упражнений · 15 подходов · ~55 мин», метка «Акцент: грудные +2 подхода», «Блок 2 · нед. 3». Блок «Решение тренера после прошлой тренировки» (например, «Жим лёжа ↑ 80 кг × 8 · Было 77,5 × 8 / 8 / 8, оценка «Нормально»») и короткий список упражнений. Кнопка «Начать тренировку».
- Метрики: «0 / 3 план недели», «6 нед серия», «83% до ур. 8: 340 XP». Блок «Питание · 1 487 / 2 450 ккал · Белка не хватает 50 г · рецепты на вечер». Задание дня «3 тренировки по плану · Отдых в вт, чт, сб, вс засчитывается · +150 XP» → Challenges.
- Нижняя навигация не перекрывает контент.
- Motion: кольцо недели и XP-полоса заполняются, каскад карточек, персонаж «дышит».
- Бэклог: C2, C3, F11, H1–H4.

### 2.2 `Ready` — Готовность перед тренировкой
- «Как вы сегодня?» Необязательно. Три группы чипов: Сон, Самочувствие, Есть боль? Блок эффекта показывает, **как ответ меняет план** (`effectTitle`, `effectText`). Предупреждение: острая или нарастающая боль — повод прекратить и обратиться к врачу. «Начать тренировку», «Пропустить вопрос». Состояния по умолчанию: сон 1, самочувствие 1, боль 0.
- Логика «плохого дня» — `data/programming_rules.md`, 4.11; боль — `data/safety_screening.md`.
- Бэклог: C4, B11.

### 2.3 `Workout` — Активная тренировка
- «Верх A · упражнение 1 из 5», таймер «12:40 · подход N из 3». Упражнение «Жим лёжа», ссылка «Техника» → Exercise. Цель тренера «↑ 80 кг · 3 × 8», «Прошлый раз 77,5 × 8/8/8», «На сторону: 20 + 10» (пересчёт для гантелей/грифа).
- Каждый подход: строка «80 × 8», быстрые кнопки «✓ Как в плане · 8», «−1», «−2», «Другое» (шаговое поле повторов − N +), «Записать». Выполненные подходы схлопываются с дельтой к плану.
- После отдыха — «Отдых 2:30» и подсказка «Свернёте приложение — бот напишет, когда пора».
- После упражнения: «Жим лёжа записан: 8/7/6», «Одна оценка на всё упражнение», «Дальше» → Rate. Предпросмотр следующих упражнений (Тяга штанги в наклоне 70 × 10 × 3, Жим гантелей сидя 22 × 10 × 3), «Заменить», «Оценить и дальше».
- Состояния в макете: `facts` по подходам, `custom`, `customReps`, `rest`.
- Motion: схлопывание подхода с лаймовым штрихом, «призрак» прошлой попытки, отскок значения, haptic medium.
- Бэклог: C5, C10, K8.

### 2.4 `Rest` — Отдых между подходами
- «Жим лёжа · после подхода 2», «Записано 80 × 7 · −1 к плану», крупный таймер «1:47 из 2:30», кнопки «−15 с / +15 с», «Следующий подход · Подход 3 из 3 · 80 × 8», «Начать подход раньше». Подсказка: если снова не добираете — нормально, итог сравнят после тренировки. Подсказка про сообщение бота «Отдых окончен…».
- Таймер должен идти в фоне и дублироваться ботом (K4).
- Motion: кольцо обратного отсчёта, haptic-тики последних 5 секунд.
- Бэклог: C6, K4.

### 2.5 `Rate` — Оценка упражнения
- «Как прошло упражнение?» Выбор (Легко / Нормально / Тяжело и т. п., по умолчанию `pick: 2`), без RPE на каждый подход. Факт «Жим лёжа · 80 × 8 / 7 / 6», чекбокс «Была боль или дискомфорт». «Сохранить · следующее упражнение» → Summary в конце.
- Бэклог: C7.

### 2.6 `Summary` — Итог и решение
- «Верх A · 54 мин · 15 подходов · план 93%». Таблица «Упражнение / План / Факт». Блок «Решения тренера · 3 изменения»: карточка с решением (→ Оставить вес / ↑ повысить), блок «Почему», пересмотр правил («8/8/8 → +2,5 кг · два провала подряд → 75 кг»), «Принять» / «Изменить». «+120 XP за тренировку по плану. Неделя 1 из 3 · уровень 7: 1780 / 2000». «Принять все и завершить» → Today.
- Объяснение пишет **ИИ-тренер** (2–3 предложения), решение даёт движок. Журнал решений обязателен (M7).
- Motion: таблица каскадом, стрелка направления, XP-полоса, смена стадии персонажа при повышении уровня.
- Бэклог: C1, C8, G2, H3, M7.

## 5. Тренировки: план, программы, упражнения

### 3.1 `Week` — План недели (вкладка «Тренировки»)
- Заголовок «Тренировки», «26 окт — 1 ноя · 1 из 3 выполнено». Сегментный переключатель **Неделя / Программы / Упражнения**. Карточка «Верх / низ · блок 2 из 4 · нед. 3 из 4». Предупреждение «Следующая неделя — разгрузка: на треть меньше подходов, веса те же. Серия не прерывается.»
- Дни: Пн Верх A (54 мин · 3 решения приняты), Вт Отдых, Ср Низ (Присед 100 × 8/8/8 · румынская тяга · +2) с «Перенести», Чт Бег · лёгкий (30 мин · можно говорить; метка «Бег»), Пт Верх B (метка «обновлено»), Сб–Вс Отдых. Карточка «Зал 3 · бег 1 · Акцент: грудные, аэробная база · изменить» → Directions.
- Бэклог: C2, C9, E1–E3.

### 3.2 `Programs` — Программы по направлениям
- «Библиотека · 22 программы», чипы направлений: Для вас, Сила, Масса, Похудение, Дом, Возвращение (расширить по направлениям E1). Подсказка «Подобрано под вас: сила и масса, 3 дня, зал, акцент на грудь. Остальное скрыто.» Чип профиля «Зал · Бег» → Directions. Карточки программ: название, код (T03, T09 …), мета (дни, инвентарь, длительность), тег «Подходит · …» (лаймовый) или нейтральный, уровень. Кнопка «Показать все 22 программы» (серым отмечаются не подходящие по дням/цели/инвентарю).
- Данные: `data/programs_T01-T22.md`, матрица в 5.6.
- Бэклог: D4, D6.

### 3.3 `ProgramDetail` — Программа: описание
- «Фулбоди ×3: масса», «T09 · масса / сила и масса», дней, объём по группам (полосы), табы дней A / B / C с составом. Кнопки «Выбрать программу» → On5, «Назад» → Programs.
- Бэклог: D3, D6.

### 3.4 `ExLib` — Упражнения по группам
- «Библиотека · 374 упражнения». Чипы групп (8): Грудные, Бицепсы, Трицепсы, Дельтовидные, Пресс, Широчайшие, Ягодичные, Квадрицепсы (расширить до полного набора мышц). «Подходит вам · N из 374», ссылка «Ваш акцент» / «Сменить акцент» → OnFocusM. Строка: силуэт-миниатюра с пульсирующим оверлеем группы, название, теги инвентаря и роли (База / Изоляция), шеврон → Exercise. Нижняя плашка «Остальные упражнения скрыты… Нужное можно найти через поиск». **Поиск обязателен** (в макете отражён подсказкой).
- Миниатюры — предрендеренные спрайты 3D-модели (раздел 6.3 промпта).
- Бэклог: D7, D9.

### 3.5 `Missed` — Пропущенная тренировка
- Сообщение бота «ср, 20:30»: «Тренировка «Низ» сегодня не отмечена. Перенести, засчитать отдых или поставить паузу?» Варианты действий (чипы с подсказкой), блок «Как изменится неделя» (дни с метками), «Применить». «Пропуск — часть плана, а не провал.»
- Бэклог: C9, K4.

### 3.6 `Progress` — Прогресс
- Переключатель периода (по умолчанию 90 дней). «План выполнен» с процентом. «Сила · расчётный максимум»: Жим лёжа (лучший 80 × 8 → 101 кг, +7), Приседания (127 кг, +11), Тяга в наклоне (плато 3 недели, → 0). «Рабочие подходы за неделю · цель 9–15» по группам с ★ у акцентной группы (Грудь 9, Спина 12, Ноги 10, Плечи 6 ↓). «Вес тела: тренд за 4 недели, без наград за цифру · 82,4 кг · +0,2/нед».
- Добавить: карта нагрузки на 3D-силуэте, графики по упражнению, замеры тела, недельный отчёт, питание.
- Бэклог: C11, G1–G7.

### 3.7 `Exercise` — Карточка упражнения
- «Жим лёжа», «Грудь · штанга · база · ваш акцент», расчётный максимум 101 кг. Вкладки (график / история / решения), таблица «Дата / План → факт / Оценка», лента решений тренера с причинами («Вес не рос 3 недели…»). Блок техники (видео по нажатию — заглушка), подсказки. «Замена с тем же решением тренера»: Жим гантелей лёжа, Жим в Смите. Основные и вспомогательные мышцы на 3D-силуэте.
- Данные упражнения — `data/exercises.*`; видео в каталоге нет (`media` — заглушка).
- Бэклог: C12, D9.

## 6. Атлет, профиль, задания, Pro

### 4.1 `Athlete` — Атлет
- «Ранг: Практик · Уровень 7 · 1780 / 2000 XP». Шкала рангов: Новичок, Любитель, Практик, Атлет, Мастер, Эксперт; пояснение «Ранг растёт от стажа и постоянства, а не от веса на штанге». Характеристики **Сила / Объём / Дисциплина** (34 / 21 / 41) с описанием источника данных. «Серия: 6 недель · рекорд 9», «Заморозки: 2 доступны · ставятся сами», «Пауза». Карточка «Направления: зал, бег · Акценты · план пересчитается» → Directions. «Задания и испытания · «12 недель по плану»: 6 / 12» → Challenges.
- Персонаж — 3D-тело того же пола (раздел 6.4 промпта), 6 стадий.
- Бэклог: H1–H3, I1.

### 4.2 `Directions` — Профиль: направления
- «Чем вы занимаетесь». Строки направлений с шаговыми счётчиками «дней в неделю» (по умолчанию зал 3, бег 1, йога 0), «Занятий в неделю: N из 5 дней», строка акцента («Акцент: …») и «Изменить» → экран акцента. «Добавить направление» → OnSport. Подсказка при перегрузе недели. Кнопка «Пересчитать неделю» → Week.
- Бэклог: E1–E3, E10, I1.

### 4.3 `OnFocusF` / 4.4 `OnFocusM` — Акцент зала (женский / мужской)
- «Какую группу мышц усилить?» **3D-силуэт** выбранного пола, до **двух** групп; вид спереди/сзади, анимированная пульсирующая подсветка (оверлеи в макете, 3D в продукте). Карточка эффекта: что изменится (например, «Больше жимов и разводок на грудь, на 2–3 подхода в неделю сверх базы (около 14 вместо 10–12)»), описания для каждой группы. «Применить с понедельника» (состояние `applied`), текущая неделя не меняется.
- Группы: грудные, бицепсы, трицепсы, дельтовидные, пресс, широчайшие, ягодичные, квадрицепсы (hotspot-боксы — `mockups/silhouettes/meta.json`).
- Состояния по умолчанию: женский — ягодичные, мужской — грудные.
- Бэклог: B5, E4, E5, E10.

### 4.5 `FocusQual` — Акцент: бег, силовые виды, йога, функциональный, дом
- Вкладки направлений: Бег / Пауэрлифтинг / Кроссфит / Йога / Функциональный / Дом. В каждой — чипы качеств (по умолчанию бег: «аэробная база»; пауэрлифтинг: «присед»; кроссфит: «зал»; йога: «гибкость», «осанка»; функциональный: «тяга»; дом: «ноги»). Карточка эффекта, «Применить».

## 11. Общие правила состояний

- **Загрузка**: скелетон по форме карточек, не спиннер; максимум 3 с до первой информации.
- **Ошибка**: что случилось + что сделать, без технических кодов (L5).
- **Пусто**: иллюстрация/значок + одно предложение + основное действие.
- **Офлайн**: плашка сверху, запись подходов продолжается, синхронизация при появлении сети.
- **Доступность**: цели нажатия 44 px, контраст 4,5:1, подписи иконок, режим «меньше движения».
