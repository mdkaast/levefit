# Пакет Levefit для Claude Code

Начните с `CLAUDE_CODE_PROMPT.md`: целиком вставьте его в первое сообщение Claude Code, запущенному в репозитории приложения.

| Папка / файл | Что внутри |
| --- | --- |
| `CLAUDE_CODE_PROMPT.md` | Подробный промпт: решения владельца, дизайн-система, motion, 3D-силуэты, функционал, фазы, формат итоговой сводки |
| `docs/BACKLOG.md` | Анализ текущего приложения и бэклог A–M (с решениями владельца от 26 октября) |
| `docs/MOCKUPS_SPEC.md` | Описание всех 33 экранов, потоки, состояния, привязка к задачам |
| `mockups/` | Макеты `.dc.html`, `canvas.json`, `silhouettes/` (PNG, `meta.json`, скрипты) |
| `data/exercises.csv`, `exercises.json` | 374 упражнения |
| `data/programs_T01-T22.md` | 22 шаблона программ и матрица выбора |
| `data/programming_rules.md`, `data_schema.md`, `safety_screening.md`, `progression_ladders_and_ru_names.md`, `gaps_and_sources.md` | Правила, схема данных, безопасность, лестницы прогрессий и канон названий, пробелы и источники |
| `research/reports/` | Два итоговых отчёта: рынок и каталог |
| `research/notes/` | 14 исходных заметок исследования |
| `inputs/` | Два исходных брифа |
| `references/3d-models/` | Референсы 3D-силуэтов: женский и мужской, 8 групп мышц, вид спереди и сзади |

Макеты открываются в браузере; шрифты Inter и Inter Tight подтягиваются с Google Fonts. Ссылки на PNG силуэтов в макетах вида `/_blob/<id>` работают только в редакторе, в пакете те же файлы лежат в `mockups/silhouettes/`.

После работы Claude Code выводит сводку изменений (раздел 11 промпта). Её нужно отправить в чат с исследователем.
