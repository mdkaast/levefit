# Levefit: анализ приложения и бэклог доработок

Oct 26, 2026 · @Max

## Решения владельца от 26 октября

- **ИИ-тренер остаётся** ключевой фишкой. Задача A3 (убрать «ИИ» из текстов) отменяется; тексты должны честно разделять роли: решения по нагрузке считает движок на правилах, ИИ-тренер объясняет и ведёт диалог.
- **Юридические вопросы пока не рассматриваем.** Блок A остаётся в бэклоге без изменений, но не блокирует работу и не входит в ближайшие фазы. Экран согласия из макета реализуется за фичефлагом, по умолчанию выключен.
- **Риски не повод убирать функции.** Питание, направления, фото и платные функции остаются в плане, риски корректируем позже.

## Резюме

Сейчас в Levefit работает только каркас: онбординг из 9 шагов, главная с заданиями, ручная запись подходов, график веса и профиль. Плана тренировок, решений тренера, библиотеки упражнений, направлений и питания в приложении нет, а на онбординге нет согласия на обработку данных о здоровье.

Анализ сделан по 18 скриншотам приложения в Telegram (iPhone) и по нашим обсуждениям: исследованию рынка, каталогу упражнений и программ, актуальным макетам на 33 экрана. Код и бэкенд я не видел, поэтому оценки трудоёмкости ориентировочные (S до 2 дней, M до 1 недели, L до 3 недель, XL больше).

Главные выводы:

- **Юридический блок.** Нет экрана согласия по 152-ФЗ, нет возрастного порога 18+, в тексте обещан «ИИ», хотя по концепции решает rule-based движок, а ИИ только объясняет.
- **Ядро продукта.** Экран «Тренировка» пока свободная форма из трёх пустых полей. Нет плана, прошлых значений, таймера отдыха, итога и решения «что делать дальше». Без этого нет главной ценности приложения.
- **Контент.** Список упражнений и программ из исследования ещё не подключён: в выпадающем списке лежит «Выпады» без группировки и фильтров.
- **Персонализация.** Целевые мышцы выбираются при регистрации на универсальном силуэте. Решено: акцент переносится в профиль, силуэты берутся мужской и женский, добавляются направления и акценты по ним.
- **Геймификация.** Персонаж это буква в круге, характеристики «Выносливость» и «Ловкость» ничем не питаются, недельное задание «40 подходов» награждает за объём, а мы решили награждать за выполнение плана.
- **Интерфейс.** Есть дефекты: поле времени в профиле выходит за карточку, значки выбора в «Образе жизни» сплющены, заголовки то заглавными, то строчными, нижняя навигация перекрывает контент.

Порядок работ: сначала исправления и юридический блок (фаза 0), затем ядро «план → подход → решение» (фаза 1), затем контент и персонализация (фазы 2–3), питание и монетизация после этого.

## Что есть сейчас

Визуальный стиль (чёрный фон, лаймовый акцент, карточки с тонкой обводкой, плавающая нижняя навигация) цельный и узнаваемый, внутри Telegram выглядит аккуратно. Проблемы в большинстве в содержании экранов, а не в стиле.

## Дорожная карта

Шесть фаз по порядку зависимости. Сроки ориентировочные для малой команды и уточняются после оценки кода. Каждая фаза закрывается проверяемым условием.

1. **Фаза 0. Хотфиксы и юридическая база (1–2 недели).** Согласие по 152-ФЗ, порог 18+, убрать «ИИ» из текстов, исправить дефекты интерфейса. *Врата:* ни один новый пользователь не проходит онбординг без согласия.
2. **Фаза 1. Ядро тренировки (4–6 недель).** Движок решений, план на неделю, экраны «Сегодня → Готовность → Тренировка → Отдых → Оценка → Итог», пропуски и переносы. *Врата:* 20 тестовых сценариев движка проходят автоматически, пользователь завершает тренировку без ручного ввода всего что уже знает приложение.
3. **Фаза 2. Контент и программы (3–4 недели, параллельно с фазой 1).** Импорт 374 упражнений, 22 шаблона, матрица подбора, библиотека и карточки. *Врата:* любой ответ онбординга даёт шаблон по матрице без пустых слотов.
4. **Фаза 3. Персонализация: направления и акценты (4–5 недель).** Выбор направлений, силуэты, акценты по направлениям, пересчёт плана. Бег, йога и кроссфит требуют отдельного контент-исследования. *Врата:* смена акцента изменяет план со следующего понедельника, текущая неделя не ломается.
5. **Фаза 4. Питание (5–7 недель).** База продуктов, дневник, цель по калориям, рецепты. Начинать только после закрытия фазы 1, иначе команда разойдётся по двум продуктам. *Врата:* дневник ведётся минимум 3 дня подряд у 50% тестовой группы.
6. **Фаза 5. Геймификация, Pro и рост (4–6 недель).** Персонаж, ранги, испытания, оплата Stars и веб, аналитика удержания. *Врата:* тестовая покупка и отмена проходят без ручной поддержки.

Сквозными задачами идут дизайн-система, аналитика событий, тесты и производительность.
