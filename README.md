# Levefit

Telegram Mini App для силовых тренировок. Приложение ведёт дневник, предлагает план и после каждой тренировки решает, что делать со следующей: добавить вес, повторить, сбросить или разгрузиться. Игровой слой (уровни, ранги, задания) награждает за выполнение плана, а не за тоннаж.

**Главный принцип.** Числа и решения (вес, подходы, повторы, разгрузка, реакция на боль) считает детерминированный движок правил. Языковая модель только объясняет решение простыми словами, а её ответ проверяется: веса берутся только из решений движка, при боли обязателен совет обратиться к врачу, ссылок нет. Любое решение пишется в журнал.

## Что умеет приложение

| Блок | Что есть |
| --- | --- |
| Онбординг | Имя, пол и силуэт, возраст, рост и вес (колёса), цель из шести, опыт, образ жизни, дни и место тренировок, направления. Согласие и порог 18+ отложены (метки `LEGAL-LATER`) |
| «Сегодня» | Карточка тренировки с составом и решением тренера, готовность (сон, энергия, боль), пропуск дня |
| Тренировка | Подходы в два касания, предзаполнение, таймер отдыха (по настенному времени, переживает сворачивание), оценка упражнения «легко / нормально / тяжело», итог «принять или изменить» |
| Офлайн | Очередь записей, идемпотентные подходы по `client_id`, сохранение хода тренировки |
| Движок решений | Двойная прогрессия, поправка по запасу повторений (RIR), сброс после второй неудачи, разгрузка (по сигналам и плановая), боль, низкая готовность, возвращение после перерыва, лёгкий день, прогрессия с собственным весом |
| Каталог | 374 упражнения (паттерн движения, мышцы с весами, инвентарь, уровень, шаг прибавки, замены), поиск, карточка упражнения |
| Программы | 22 шаблона (T01–T22), матрица подбора цель × дни × уровень × инвентарь (454 строки), условия «перерыв», «50+», «до 30 минут», «сплит» |
| Направления и неделя | Зал, пауэрлифтинг, кроссфит, функциональный, бег, йога, дом, универсальный. Планировщик недели, акцент на группы мышц (до двух из восьми), предпросмотр «до / после», изменения с ближайшего понедельника |
| Питание | Дневник (четыре приёма пищи, граммы и штуки, недавние и частые), цель по калориям и БЖУ с видимой формулой и защитными правилами, 129 продуктов, 100 рецептов с подбором под остаток дня и тренировку, блок на «Сегодня». База продуктов и правила не проверены специалистами |
| Профиль и прочее | Напоминания через бота, режим паузы, вес и график, достижения и задания, админ-панель (метрики, журнал ИИ), «меньше движения», тактильный отклик |

Чего пока нет: подписки Pro, настоящих 3D-силуэтов (работает 2D-вариант), контента для бега, йоги и кроссфита глубже заготовок, видео техники. Подробный список и статус по ID задач — в [docs/BACKLOG.md](docs/BACKLOG.md).

## Архитектура

```
Telegram ── бот (aiogram) ── кнопка Mini App
                │
          Caddy (HTTPS) ──┬── web: React + Vite (статика)
                          └── /api ── FastAPI ── PostgreSQL
                                        │
                                        └── (необязательно) Anthropic API: только объяснения
```

| Папка | Назначение |
| --- | --- |
| `apps/api` | FastAPI, SQLAlchemy 2, Alembic (миграции 0001–0017), движок, каталог, планировщик |
| `apps/web` | React 18, TypeScript, Vite, Telegram SDK, vitest |
| `apps/bot` | Бот на aiogram: `/start`, кнопка приложения, напоминания |
| `data/` | Исходные данные исследования: каталог упражнений, шаблоны программ, правила, безопасность |
| `docs/` | Решения, движок, каталог, направления, бэклог, аудит, сервер |
| `mockups/`, `references/` | Макеты экранов и референсы силуэтов |
| `infra/` | Общий прокси Caddy и скрипт настройки сервера |
| `scripts/` | Конвертер каталога, выкладка, запуск локального стенда |

### Бэкенд (`apps/api/app`)

| Модуль | Что делает |
| --- | --- |
| `engine/` | Чистые функции правил без БД и сети; `RULES_VERSION` в `rules.py` |
| `decisions.py`, `adjust.py` | Сбор истории, вызов движка, журнал решений в `ai_adjustments`, `GET /plan` |
| `ai/` | Только объяснение решений, проверка ответа (`safety.py`), шаблонный ответ при сбое |
| `cycle.py`, `workouts.py` | Подходы, оценки, пропуски, правки решений, итог тренировки |
| `content/` | Данные каталога и шаблонов, подбор упражнения в слот, матрица, загрузка в БД |
| `catalog.py`, `programs.py` | API каталога и программ, подбор под профиль |
| `week.py`, `planner.py` | Направления, недельный план, акценты, предпросмотр |
| `nutrition*.py`, `foodsource.py` | Дневник питания, цель, продукты, рецепты |
| `game_rules/`, `game.py` | Игровые правила (XP, уровни, ранги, задания) |
| `admin.py`, `reminders.py` | Админ-панель, напоминания |

Игровые правила считает только сервер. Миграции только через Alembic, все аддитивные и обратимые.

### Недельный план

Неделя строится из направлений пользователя и замораживается при первом обращении, поэтому смена акцента или направлений не меняет идущую неделю, а действует с ближайшего понедельника. Правила расстановки: тяжёлые ноги и интервалы не в соседних днях, подряд не больше трёх занятий, не больше пяти занятий в неделю. Пока пользователь не перешёл на программу, план «Сегодня» строится от предыдущей тренировки. Подробности: [docs/directions.md](docs/directions.md).

## Быстрый старт

Нужны Python 3.12, Node 20+, Docker (для полного стенда).

```bash
cp .env.example .env     # заполнить BOT_TOKEN, WEBAPP_URL, APP_SECRET
docker compose up --build
```

- API: http://localhost:8000/health
- Web: http://localhost:5173

Без Docker (SQLite):

```bash
cd apps/api && pip install -r requirements-dev.txt
alembic upgrade head && python -m app.content.seed   # схема и каталог
uvicorn app.main:app --port 8000

cd apps/web && npm install && npm run dev
```

Вне Telegram приложение открывается с тестовыми данными входа (`VITE_DEV_INIT_DATA`, получить: `python scripts/make_dev_init_data.py`). Только для локальной разработки.

### Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `BOT_TOKEN` | Токен бота из BotFather (подпись входа и бот) |
| `WEBAPP_URL` | Публичный HTTPS-адрес Mini App |
| `APP_SECRET` | Ключ подписи токенов API |
| `DATABASE_URL` | Строка подключения к БД |
| `CORS_ORIGINS` | Разрешённые источники |
| `ANTHROPIC_API_KEY`, `LLM_MODEL` | Необязательно: без ключа объяснения даёт шаблон |
| `ADMIN_TELEGRAM_IDS` | Кто видит админ-панель |

Секреты хранятся только в `.env` и на сервере, в репозиторий не попадают.

## Проверки

```bash
cd apps/api && ruff check . && pytest
cd apps/bot && ruff check . && pytest
cd apps/web && npm run lint && npx tsc --noEmit && npm test && npm run build
```

CI (GitHub Actions) запускает те же проверки на каждый push. Сейчас: API 296 тестов, веб 55.

## Каталог и данные

`data/exercises.json` преобразуется скриптом в готовый JSON внутри `apps/api/app/content/`:

```bash
python -X utf8 scripts/build_catalog.py
```

Загрузка в БД идёт при старте API и ничего не удаляет. Спорные места помечены `verified: false`: все шаблоны (нужна проверка тренером и врачом ЛФК), 40 упражнений с неустоявшимися названиями, заготовки бега, йоги, кроссфита и функционального тренинга. Описание: [docs/catalog.md](docs/catalog.md).

## Выкладка

Один VPS, Docker Compose, общий Caddy с Let's Encrypt.

```bash
bash scripts/deploy_vps.sh          # выкладывает текущий коммит
```

Правила команды: перед миграциями делается `pg_dump`; в `main` вливаем по решению владельца; секреты лежат только на сервере. Подробности: [docs/server.md](docs/server.md).

## Дорожная карта

Фазы 0–4 выполнены (хотфиксы и основа интерфейса, ядро тренировки, каталог и шаблоны, направления и акценты, питание). Дальше: проверка базы продуктов и правил питания специалистами, настоящие 3D-силуэты, исследование бега, йоги и кроссфита, затем геймификация, Pro и рост (фаза 5).

## Ограничения

Приложение не заменяет врача и тренера. При боли нагрузка снижается, а пользователю советуют обратиться к специалисту. Юридический блок (согласие на обработку данных, возрастной порог, политика) отложен и отмечен в коде `LEGAL-LATER`.
